# Wintage

**Тема Win95 темно-золотого вінтажу для всього вебу.** Це Tampermonkey-юзерскрипт, який перетворює кожен сайт на темно-золоту застосунку Windows 95: піксель-чіткі 3D-фаски, нуль заокруглених кутів, нуль анімацій, без ховер-спалахів, Verdana всюди.

[🤍 Підтримати розробника](https://buymeacoffee.com/vacuum34)

[EN](README.md) | [RU](README.ru.md) | [ET](README.et.md) | [Дед](README.ded.md)

_Сучасний веб оптимізує естетику за рахунок зручності. Заокруглені кути замінюють візуальну ієрархію, анімації — зворотний зв'язок, тіні — структуру, а мінімалізм часто прибирає саме ті підказки, на які покладається мозок, щоб зрозуміти інтерфейс._

_Користувач не повинен вгадувати, чи це кнопка, мітка, картка чи просто текст. Wintage повертає однозначну візуальну мову: підняті кнопки, заглиблені поля вводу, різкі межі, послідовна типографіка, нуль відволікань і миттєві зміни стану._

_Кожен елемент повідомляє своє призначення з першого погляду, знижуючи когнітивне навантаження і перетворюючи веб на точний інструмент замість колекції декоративних бульбашок._

## Встановлення

1. Встановіть [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Opera, Safari).
2. Натисніть **[Встановити Wintage](https://raw.githubusercontent.com/vacterro/Wintage/main/wintage.user.js)** — Tampermonkey автоматично відкриє сторінку встановлення.
3. Готово. Кожен сайт, який ви відвідуєте, тепер працює на Windows 95, темно-золоте видання.

## Оновлення

- **Автоматично:** скрипт має `@updateURL`/`@downloadURL`, що вказує на цей репозиторій, тому Tampermonkey підхоплює нові версії під час регулярних перевірок оновлень.
- **Оновлення вручну:** Tampermonkey → **Utilities → Check for userscript updates**, або просто натисніть посилання встановлення ще раз — воно замінить стару версію без деінсталяції.
- **Відсутні рядки тем означають старий скрипт:** меню створюється зі вбудованого реєстру тем, і релізний тест вимагає рівно один рядок меню для кожної вбудованої палітри. Якщо меню коротше за список палітр нижче, натисніть знову **Install Wintage** і підтвердьте **Update** у Tampermonkey.

## Шістнадцять палітр і перемикач

Wintage більше не одна палітра. Шість — це структура UI.md, повернута в іншу колірну родину (Dark Golden, Claude Code, Antigravity, K-Lite, FreeBuff, CodeNomad); Custom можна редагувати і зберігати з десктопного інсталятора, а дев'ять імпортовано з [FastPrompter](https://github.com/vacterro) (Default, Golden Vintage, Golden Default, Vintage Dark, Vintage Classic, Dark 2 OLED, Dracula, Nord, Solarized Dark). Кожна проходить WCAG AA на трьох токенах, що несуть текст, — збірний шлюз відхиляє палітру, яка цього не проходить.

Оберіть одну з **меню Tampermonkey** на будь-якій сторінці; вибір зберігається на користувача, а не на сайт, тому діє на всіх доменах.

Палітри живуть у `themes/*.json`, поза скриптом, з однієї причини: Tampermonkey повторно завантажує `wintage.user.js` при кожному оновленні, тож палітра, вписана вручну, зникла б. Повторно застосуйте їх на свіжий збірник:

```powershell
.\install-themes.ps1 -Latest
```

## За межами браузера

Ті самі палітри встановлюються в десктопні застосунки — VS Code та Antigravity як колірні теми, Electron-застосунки (Freebuff, Antigravity agent app) через шім, який впорскує саме той стильовий файл, що й цей юзерскрипт. Для цього є маленька GUI:

Двічі клацніть **`Wintage Installer.vbs`** у корені репозиторію. Вона відкриває GUI без консольного вікна. Застарілий `.cmd`-лаунчер переадресовує на той самий прихований хост; `desktop\WintageInstaller.ps1` можна запускати напряму для діагностики.

Що кожна ціль може й не може досягти — включно з двома застосунками, які запечатані або мають вкомпільовані кольори, — описано в **[desktop/README.md](desktop/README.md)**.

## Можливості

- **Палітра Golden Default** — глибокий коричнево-чорний канвас `#1A1810`, золотий текст `#D4C89A`, золоті фаски-хайлайти `#F0D060`. Тільки суцільні плоскі поверхні: без градієнтів, без блюру, без ефектів прозорості.
- **Класичні 3D-фаски** — кнопки підняті, поля вводу заглиблені, натиснуті кнопки вдавлюються (з автентичним зсувом підпису на 1px). Скролбари повні 16px у стилі Win95, з фасочним повзунком і кнопками.
- **Вбивця радіусів** — `border-radius: 0` примусово всюди, включно з CSS-змінними фреймворків (Bootstrap, Material, YouTube, Reddit).
- **Рух заборонено** — усі переходи та анімації обнулені. Зміни стану миттєві, як у справжньому інтерфейсі 1995 року.
- **Ховер-підсвітку повністю вимкнено** — без білих спалах-рядків, без сірих блоків тонування:
  - властивості заливки хірургічно вирізаються з кожного читаного CSS-правила `:hover` (функціональні властивості на кшталт `display`/`visibility`/`opacity` зберігаються, тому меню, що відкриваються при наведенні, працюють далі);
  - нечитані крос-оріджин стилі нейтралізуються фолбеком заморожування переходів.
  Лише справжні елементи керування (кнопки, посилання, поля вводу) зберігають миттєву тематизовану фасочну реакцію.
- **Verdana примусово 100% всюди** — включно з полями вводу та textarea, з вимкненим згладжуванням шрифтів. Іконкові шрифти виключені, щоб гліфи не перетворювалися на літери. Якщо встановлено кастомний шрифт під назвою `Verdana_m1` (наприклад, патч Verdana без антиаліасингу), він використовується автоматично; інакше звичайна Verdana.
- **Адаптивний репайнтер** — легкий JS-сканер перетворює світлі «спалах»-поверхні та незатемнені сірі темного режиму на вінтажну коричневу шкалу і виправляє низькоконтрастний (темний-на-темному) текст на золотий на WCAG-свідомих порогах. Зображення, відео, канваси та плеєри ніколи не чіпаються.
- **Проникнення в Shadow DOM** — тематизує і веб-компоненти (YouTube, Reddit та інших) через хук `attachShadow`.
- **Попапи поводяться** — меню, діалоги, тултіпи та ховеркарди лише перефарбовуються; скрипт ніколи не примушує `opacity`/`z-index`/`visibility`, тому прихований UI сайту лишається прихованим.
- **Захисник безпеки** — скрипт вимикається на сторінках OAuth, капчі, банкінгу та оплати, щоб критичні процеси ніколи не перестилізовувалися.

## Відповідна браузерна тема

Ціль `browsers` десктопного інсталятора виявляє встановлені та портативні профілі Chromium, повідомляє про покриття Tampermonkey, готує вибрану браузерну тему та відкриває правильні сторінки встановлення/оновлення для кожного профілю. Chromium вимагає одне підтвердження **Developer mode → Load unpacked** на профіль; інсталятор копіює стабільний шлях теми в буфер обміну. Пізніші зміни палітри використовують цей шлях знову.

## Відомі особливості поведінки

- Сайти, які будують ховер-ефекти в JavaScript (зміною класів) замість CSS `:hover`, можуть показувати власне підсвічування.
- На рідкісних сайтах з крос-оріджин CSS клік по нефокусованому елементу може затримувати візуальну зміну стану, доки миша його не покине (спрацьовує фолбек заморожування ховера). Справжні кнопки та посилання виключені.
- Скрипт навмисно статичний: жодної панелі налаштувань, жодних перемикачів для конкретних сайтів. Форкніть і відредагуйте токени вище, якщо хочете інший смак.

## Випуск нової версії (для мейнтейнерів)

Відредагуйте `wintage.user.js`, потім запустіть:

```powershell
.\release.ps1 -Message "що змінилося"
```

Він піднімає номер `@version`-патча, комітить і пушить — клієнти Tampermonkey підхоплять оновлення автоматично. Для більших релізів передайте `-Bump minor` або `-Bump major`.
