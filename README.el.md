# Wintage

**Σκούρα χρυσή vintage θέμα Win95 για ολόκληρο το διαδίκτυο.** Ένα userscript Tampermonkey που αναδιαμορφώνει κάθε ιστοσελίδα σε σκούρα καφέ-χρυσή εφαρμογή Windows 95: ευκρινείς στο pixel τρισδιάστατες φασέτες, μηδέν στρογγυλεμένες γωνίες, μηδέν animations, χωρίς λάμψεις στο hover, Verdana παντού.
[🤍 Υποστήριξε τον προγραμματιστή](https://buymeacoffee.com/vacuum34)

[EN](README.md) | [RU](README.ru.md) | [ET](README.et.md) | [Дед](README.ded.md)

_Το σύγχρονο διαδίκτυο βελτιστοποιεί την αισθητική εις βάρος της χρηστικότητας. Οι στρογγυλεμένες γωνίες αντικαθιστούν την οπτική ιεραρχία, τα animations την ανατροφοδότηση, οι σκιές τη δομή, και ο μινιμαλισμός συχνά αφαιρεί ακριβώς τα στοιχεία στα οποία στηρίζεται ο εγκέφαλός μας για να κατανοήσει μια διεπαφή._

_Ο χρήστης δεν θα έπρεπε να μαντεύει αν κάτι είναι κουμπί, ετικέτα, κάρτα ή απλό κείμενο. Το Wintage φέρνει πίσω την ξεκάθαρη οπτική γλώσσα: ανυψωμένα κουμπιά, βυθισμένα πεδία, αιχμηρά όρια, συνεπή τυπογραφία, μηδέν περισπασμοί και άμεσες αλλαγές κατάστασης._

_Κάθε στοιχείο επικοινωνεί τον σκοπό του με μια ματιά, μειώνοντας το γνωστικό φορτίο και κάνοντας το διαδίκτυο να μοιάζει ξανά με ακριβές όργανο αντί για συλλογή διακοσμητικών φυσαλίδων._

## Εγκατάσταση

1. Εγκαταστήστε το [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Opera, Safari).
2. Κάντε κλικ στο **[Εγκατάσταση Wintage](https://raw.githubusercontent.com/vacterro/Wintage/main/wintage.user.js)** — το Tampermonkey ανοίγει αυτόματα τη σελίδα εγκατάστασης.
3. Έτοιμο. Κάθε ιστοσελίδα που επισκέπτεστε τρέχει πλέον Windows 95, έκδοση Dark Golden.

## Ενημέρωση

- **Αυτόματα:** το script φέρει `@updateURL`/`@downloadURL` που δείχνουν σε αυτό το repo, οπότε το Tampermonkey παραλαμβάνει τις νέες εκδόσεις στους τακτικούς ελέγχους ενημέρωσης.
- **Χειροκίνητη ανανέωση:** Tampermonkey → **Utilities → Check for userscript updates**, ή απλώς κάντε ξανά κλικ στον σύνδεσμο εγκατάστασης — αντικαθιστά την παλιά έκδοση επί τόπου, χωρίς να χρειάζεται απεγκατάσταση.
- **Λείπουν σειρές θεμάτων — σημαίνει παλιό script:** το μενού παράγεται από το ενσωματωμένο μητρώο θεμάτων και η δοκιμή έκδοσης απαιτεί ακριβώς μία σειρά μενού για κάθε ενσωματωμένη παλέτα. Αν το μενού είναι μικρότερο από τη λίστα παλετών παρακάτω, κάντε ξανά κλικ στο **Εγκατάσταση Wintage** και επιβεβαιώστε το **Update** στο Tampermonkey.

## Δεκαέξι παλέτες και ένας διακόπτης

Το Wintage δεν είναι πλέον μία παλέτα. Έξι είναι η δική του δομή του UI.md περιστραμμένη σε άλλη οικογένεια αποχρώσεων (Dark Golden, Claude Code, Antigravity, K-Lite, FreeBuff, CodeNomad)· το Custom μπορεί να επεξεργαστεί και να αποθηκευτεί από τον εγκαταστάτη επιφάνειας εργασίας, και εννέα εισάγονται από το [FastPrompter](https://github.com/vacterro) (Default, Golden Vintage, Golden Default, Vintage Dark, Vintage Classic, Dark 2 OLED, Dracula, Nord, Solarized Dark). Κάθε μία από αυτές περνά το WCAG AA στα τρία tokens που φέρουν κείμενο — η πύλη build αρνείται κάθε παλέτα που δεν το καταφέρνει.

Διαλέξτε μία από το **μενού Tampermonkey** σε οποιαδήποτε σελίδα· η επιλογή αποθηκεύεται ανά χρήστη, όχι ανά ιστοσελίδα, οπότε ισχύει σε κάθε τομέα.

Οι παλέτες ζουν στο `themes/*.json`, έξω από το script, για έναν λόγο: το Tampermonkey κατεβάζει εκ νέου το `wintage.user.js` σε κάθε ενημέρωση, οπότε μια παλέτα που θα προστεθεί χειροκίνητα μέσα του θα εξαφανιζόταν. Εφαρμόστε τες ξανά σε ένα φρέσκο build με:

```powershell
.\install-themes.ps1 -Latest
```

## Πέρα από τον browser

Οι ίδιες παλέτες εγκαθίστανται σε εφαρμογές επιφάνειας εργασίας — σε VS Code και Antigravity ως χρωματικά θέματα, σε Electron εφαρμογές (Freebuff, η εφαρμογή πράκτορα Antigravity) μέσω ενός shim που εισάγει ακριβώς το stylesheet που χρησιμοποιεί αυτό το userscript. Υπάρχει ένα μικρό GUI για αυτό:

Κάντε διπλό κλικ στο **`Wintage Installer.vbs`** στη ρίζα του repo. Ανοίγει το GUI χωρίς παράθυρο κονσόλας. Ο παλιός εκκινητής `.cmd` προωθεί στον ίδιο κρυφό host· το `desktop\WintageInstaller.ps1` μπορεί ακόμα να τρέξει απευθείας για διαγνωστικά.

Τι μπορεί και τι δεν μπορεί να φτάσει κάθε στόχος — συμπεριλαμβανομένων των δύο εφαρμογών που είναι συγκολλημένες ή με χρώματα ενσωματωμένα — είναι καταγεγραμμένο στο **[desktop/README.md](desktop/README.md)**.

## Χαρακτηριστικά

- **Παλέτα Golden Default** — βαθύς καφέ-μαύρος καμβάς `#1A1810`, χρυσό κείμενο `#D4C89A`, χρυσά highlights φασετών `#F0D060`. Μόνο συμπαγείς επίπεδες επιφάνειες: καμία διαβάθμιση, κανένα θάμπωμα, κανένα εφέ διαφάνειας.
- **Κλασικές τρισδιάστατες φασέτες** — τα κουμπιά είναι ανυψωμένα, τα πεδία βυθισμένα, το πατημένο κουμπί βυθίζεται (με τη γνήσια μετατόπιση ετικέτας κατά 1px). Οι μπάρες κύλισης είναι πλήρεις 16px σε στυλ Win95, με φασέτα και κουμπιά.
- **Δολοφόνος ακτίνων** — `border-radius: 0` επιβάλλεται παντού, συμπεριλαμβανομένων των CSS μεταβλητών των frameworks (Bootstrap, Material, YouTube, Reddit).
- **Η κίνηση απαγορεύεται** — όλες οι μεταβάσεις και τα animations μηδενίζονται. Οι αλλαγές κατάστασης είναι άμεσες, σαν πραγματικό UI του 1995.
- **Το hover-highlighting απενεργοποιημένο εντελώς** — χωρίς λευκές σειρές-λάμψεις, χωρίς γκρι μπλοκ:
  - τα properties βαφής αφαιρούνται χειρουργικά από κάθε αναγνώσιμο κανόνα CSS `:hover` (τα λειτουργικά properties όπως `display`/`visibility`/`opacity` διατηρούνται, οπότε τα μενού που ανοίγουν στο hover συνεχίζουν να δουλεύουν);
  - τα δυσανάγνωστα stylesheets από άλλη προέλευση εξουδετερώνονται με ένα εφεδρικό πάγωμα μεταβάσεων.
  Μόνο τα πραγματικά controls (κουμπιά, σύνδεσμοι, πεδία) διατηρούν άμεση, θεματική απόκριση φασέτας.
- **Verdana αναγκαστικά 100% παντού** — συμπεριλαμβανομένων των πεδίων και των textareas, με απενεργοποιημένο το smoothing γραμματοσειράς. Οι γραμματοσειρές εικονιδίων εξαιρούνται για να μην μετατραπούν τα glyphs σε γράμματα. Αν έχετε εγκατεστημένη προσαρμοσμένη γραμματοσειρά με το όνομα `Verdana_m1` (π.χ. ένα patch Verdana χωρίς anti-aliasing), χρησιμοποιείται αυτόματα· διαφορετικά η κανονική Verdana.
- **Προσαρμοστικός επαναβάφτης** — ένας ελαφρύς καθαριστής JS μετατρέπει τις φωτεινές επιφάνειες "flashbang" και τα άθετα γκρι σκούρου τρόπου σε vintage καφέ κλίμακα, και διορθώνει το κείμενο χαμηλής αντίθεσης (σκοτεινό πάνω σε σκοτεινό) σε χρυσό, με όρια ευαίσθητα στο WCAG. Εικόνες, βίντεο, canvases και players δεν αγγίζονται ποτέ.
- **Διείσδυση Shadow DOM** — θέτει θέματα και σε web components (YouTube, Reddit κ.ά.) μέσω ενός hook `attachShadow`.
- **Τα popups συμπεριφέρονται σωστά** — μενού, διάλογοι, tooltips και hovercards μόνο χρωματίζονται ξανά· το script δεν επιβάλλει ποτέ `opacity`/`z-index`/`visibility`, οπότε το κρυφό UI της ιστοσελίδας παραμένει κρυφό.
- **Ασφαλιστική δικλείδα** — το script απενεργοποιεί τον εαυτό του σε OAuth, captcha, τραπεζικές και πληρωμών σελίδες, ώστε τα κρίσιμα ρεύματα να μην αναδιαμορφώνονται ποτέ.

## Παλέτα

Ο παρακάτω πίνακας δείχνει 10 από τα 21 tokens της παλέτας Golden Default. Κάθε
παλέτα που διατίθεται ορίζει και τα 21· τα υπόλοιπα 11 καλύπτουν τη δομή των
φασετών, το δευτερεύον κείμενο, τα σημασιολογικά χρώματα (επιτυχία/προειδοποίηση/
κίνδυνος), την επιλογή και τις λεπτομέρειες ανά στόχο.

| Token | Hex | Χρησιμεύει για |
|---|---|---|
| background | `#1A1810` | εξώτατο φόντο |
| backgroundSoft | `#232018` | φόντο σώματος / περιεχομένου |
| surface | `#332E22` | επικεφαλίδες, πλοήγηση, πάνελ |
| surfaceRaised | `#3D372A` | κουμπιά, popups, λαβή μπάρας κύλισης |
| surfaceAlt | `#453D30` | hover κουμπιού |
| borderHighlight | `#F0D060` | πάνω-αριστερά 3D άκρα |
| borderDark | `#100E08` | κάτω-δεξιά 3D άκρα |
| textPrimary | `#D4C89A` | κύριο χρυσό κείμενο |
| textMuted | `#6E674E` | placeholders, απενεργοποιημένα |
| link | `#F0D060` | σύνδεσμοι, focus |

## Ταίριαστο θέμα browser

Ο στόχος `browsers` του εγκαταστάτη επιφάνειας εργασίας εντοπίζει εγκατεστημένα και φορητά προφίλ Chromium, αναφέρει την κάλυψη Tampermonkey, προετοιμάζει το επιλεγμένο θέμα browser και ανοίγει τις σωστές σελίδες εγκατάστασης/ενημέρωσης για κάθε προφίλ. Το Chromium απαιτεί μία επιβεβαίωση **Developer mode → Load unpacked** ανά προφίλ· ο εγκαταστάτης αντιγράφει τη σταθερή διαδρομή θέματος στο πρόχειρο. Οι μεταγενέστερες αλλαγές παλέτας επαναχρησιμοποιούν αυτή τη διαδρομή.

## Γνωστές συμπεριφορές

- Ιστοσελίδες που χτίζουν τα εφέ hover σε JavaScript (εναλλαγή κλάσεων) αντί για CSS `:hover` μπορεί να εμφανίζουν ακόμα το δικό τους highlight.
- Σε σπάνιες ιστοσελίδες των οποίων το CSS είναι cross-origin, το κλικ σε ένα μη εστιάσιμο στοιχείο μπορεί να καθυστερήσει την οπτική αλλαγή κατάστασης μέχρι να φύγει το ποντίκι (λειτουργεί το εφεδρικό πάγωμα hover). Τα πραγματικά κουμπιά και οι σύνδεσμοι εξαιρούνται.
- Το script είναι στατικό εκ σχεδιασμού: χωρίς πίνακα επιλογών, χωρίς διακόπτες ανά ιστοσελίδα. Κάντε fork και επεξεργαστείτε τα tokens στην κορυφή αν θέλετε διαφορετική γεύση.

## Κυκλοφορία νέας έκδοσης (συντηρητές)

Επεξεργαστείτε το `wintage.user.js` και μετά εκτελέστε:

```powershell
.\release.ps1 -Message "τι άλλαξε"
```

Αυξάνει τον αριθμό patch του `@version`, κάνει commit και push — οι πελάτες Tampermonkey παραλαμβάνουν την ενημέρωση αυτόματα. Για μεγαλύτερες εκδόσεις δώστε `-Bump minor` ή `-Bump major`.
