Vintage Win 95 Dark Golden — motyw przeglądarki (Cent Browser / Chrome / Edge)
==========================================================================

Motyw towarzyszący userskryptowi Wintage (https://github.com/vacterro/Wintage).
Ten motyw to stała, odziedziczona paleta Dark Golden, ręcznie spakowana i niezależna
od przełączanych palet userskryptu: canvas #1A0F05, toolbar #2A1C0A, golden text
#D4B87A, bevel gold #C0A060, sunken omnibox #0F0A04, link accent #9DD9F9. Nie
podąża za domyślną paletą skryptu (Golden Default) ani za pakietami themes/*.json —
pozostaje przy klasycznym wyglądzie Dark Golden, dla którego ten motyw przeglądarki
został stworzony.

INSTALACJA:
  1. Otwórz chrome://extensions
  2. Włącz «Developer mode» (w prawym górnym rogu)
  3. Kliknij «Load unpacked» i wybierz ten folder (vintage_theme)
  4. Motyw jest stosowany natychmiast. Po edycjach załaduj go ponownie w ten sam sposób.

PRZYWRÓCENIE:
  Ustawienia -> Wygląd -> «Reset to default» lub usuń motyw
  z chrome://extensions.

Token mapping:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
