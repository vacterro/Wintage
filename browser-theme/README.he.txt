Vintage Win 95 Dark Golden — נושא דפדפן (Cent Browser / Chrome / Edge)
==========================================================================

נושא נלווה לסקריפט המשתמש Wintage (https://github.com/vacterro/Wintage).
נושא זה הוא פלטת Dark Golden מורשת קבועה, ארוזה ידנית ובלתי תלויה בפלטות
הניתנות להחלפה של הסקריפט: canvas #1A0F05, toolbar #2A1C0A, טקסט זהוב
#D4B87A, שפה זהובה #C0A060, שדה כתובת שקוע #0F0A04, הדגשת קישורים #9DD9F9.
הוא אינו עוקב אחר ברירת המחדל של הסקריפט (Golden Default) ולא אחרי חבילות
themes/*.json — הוא נשאר במראה Dark Golden הקלאסי שעליו נבנה נושא דפדפן זה.

INSTALL:
  1. פתחו את chrome://extensions
  2. הפעילו "Developer mode" (למעלה מימין)
  3. לחצו "Load unpacked" ובחרו את התיקייה הזו (vintage_theme)
  4. הנושא מוחל מיד. טענו אותו מחדש באותה דרך אחרי עריכות.

REVERT:
  Settings -> Appearance -> "Reset to default", או הסירו את הנושא
  מ-chrome://extensions.

מיפוי אסימונים:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
