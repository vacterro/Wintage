Vintage Win 95 Dark Golden — tema de navegador (Cent Browser / Chrome / Edge)
=============================================================================

Tema complementario del userscript de Wintage (https://github.com/vacterro/Wintage).
Este tema es una paleta Dark Golden heredada y fija, empaquetada a mano e independiente
de las paletas conmutables del userscript: canvas #1A0F05, barra de herramientas #2A1C0A, texto dorado
#D4B87A, oro de bisel #C0A060, omnibox hundida #0F0A04, acento de enlace #9DD9F9. No sigue
ni el valor predeterminado del script (Golden Default) ni los paquetes themes/*.json: se
mantiene en el aspecto Dark Golden clásico con el que se construyó este tema de navegador.

INSTALACIÓN:
  1. Abre chrome://extensions
  2. Activa "Developer mode" (arriba a la derecha)
  3. Haz clic en "Load unpacked" y selecciona esta carpeta (vintage_theme)
  4. El tema se aplica de inmediato. Vuelve a cargarlo de la misma manera tras las ediciones.

REVERTIR:
  Settings -> Appearance -> "Reset to default", o quita el tema
  desde chrome://extensions.

Mapeo de tokens:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
