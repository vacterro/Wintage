# Wintage

**Web全体をWin95ダークゴールデンヴィンテージテーマに。** すべてのサイトをダークな金褐色のWindows 95アプリケーションに再スタイルするTampermonkeyユーザースクリプト: ピクセルシャープな3Dベベル、角丸ゼロ、アニメーションゼロ、ホバーフラッシュなし、どこでもVerdana。

[🤍 開発者を支援](https://buymeacoffee.com/vacuum34)

[EN](README.md) | [RU](README.ru.md) | [ET](README.et.md) | [Дед](README.ded.md)

_モダンなWebは、使いやすさを犠牲にして見た目を最適化している。角丸は視覚的な階層を置き換え、アニメーションはフィードバックを置き換え、シャドウは構造を置き換え、ミニマリズムはインターフェースを理解するために脳が頼る手がかりそのものを奪ってしまう。_

_ユーザーは、それがボタンなのか、ラベルなのか、カードなのか、単なるテキストなのかを推測するべきではない。Wintageは明快な視覚言語を取り戻す: 浮き出たボタン、沈み込んだ入力欄、はっきりした境界線、一貫したタイポグラフィ、気を散らすものがゼロ、即時の状態変化。_

_あらゆる要素が一目でその役割を伝える。これにより認知負荷が下がり、Webは装飾的な泡の集まりではなく、再び精密な道具のように感じられる。_

## インストール

1. [Tampermonkey](https://www.tampermonkey.net/) をインストールする (Chrome, Edge, Firefox, Opera, Safari)。
2. **[Wintageをインストール](https://raw.githubusercontent.com/vacterro/Wintage/main/wintage.user.js)** をクリック — Tampermonkeyがインストールページを自動的に開く。
3. 完了。アクセスするすべてのサイトが、ダークゴールデン版のWindows 95で動く。

## 更新

- **自動:** スクリプトはこのリポジトリを指す `@updateURL`/`@downloadURL` を保持しているので、Tampermonkeyは定期の更新チェックで新バージョンを取得する。
- **手動更新:** Tampermonkey → **Utilities → Check for userscript updates**、あるいはインストールリンクをもう一度クリック — 旧バージョンをその場で置き換えるので、アンインストールは不要。
- **テーマの行が足りない場合は古いスクリプト:** メニューは組み込みのテーマレジストリから生成され、リリーステストでは各パレットにちょうど1つのメニュー行が必要。メニューが下記のパレット一覧より短い場合は、**Install Wintage** をもう一度クリックし、Tampermonkeyで **Update** を確認する。

## 16パレットとスイッチ

Wintageはもはや1つのパレットではない。6つはUI.md自身の構造を別の色相ファミリーに回転させたもの (Dark Golden, Claude Code, Antigravity, K-Lite, FreeBuff, CodeNomad)。Customはデスクトップインストーラーから編集・保存できる。残り9つは [FastPrompter](https://github.com/vacterro) からインポートされたもの (Default, Golden Vintage, Golden Default, Vintage Dark, Vintage Classic, Dark 2 OLED, Dracula, Nord, Solarized Dark)。そのすべてが、テキストを担う3つのトークンでWCAG AAをクリアする — ビルドゲートはクリアできないパレットを拒否する。

どのページでも **Tampermonkeyメニュー** から1つ選ぶ。選択はサイトごとではなくユーザーごとに保存されるので、すべてのドメインで有効。

パレットはスクリプトの外、`themes/*.json` にある。理由は1つ: Tampermonkeyは更新のたびに `wintage.user.js` を再ダウンロードするので、手で書き込んだパレットは消えてしまう。新しいビルドに再適用するには:

```powershell
.\install-themes.ps1 -Latest
```

## ブラウザを超えて

同じパレットがデスクトップアプリにもインストールできる — VS CodeとAntigravityにはカラーテーマとして、Electronアプリ (Freebuff、Antigravityエージェントアプリ) には、このユーザースクリプトが使うのと同じスタイルシートを注入するシム経由。専用の小さなGUIもある:

リポジトリルートの **`Wintage Installer.vbs`** をダブルクリック。コンソールウィンドウなしでGUIが開く。レガシーな `.cmd` ランチャーは同じ隠しホストに転送する。`desktop\WintageInstaller.ps1` は診断用に直接実行もできる。

各ターゲットがどこまで到達でき、どこに到達できないか — 溶接されて閉じている、または色がコンパイルされている2つのアプリを含む — は **[desktop/README.md](desktop/README.md)** に記載。

## 機能

- **Golden Default パレット** — 深い茶黒キャンバス `#1A1810`、金色テキスト `#D4C89A`、金色ベベルハイライト `#F0D060`。フラットな面だけ: グラデーションなし、ぼかしなし、透明効果なし。
- **クラシックな3Dベベル** — ボタンは浮き出て、入力欄は沈み込み、押したボタンは押し込まれる (本物同様の1pxラベルシフト付き)。スクロールバーは完全な16px Win95スタイル、ベベル付きのつまみとボタン付き。
- **角丸キラー** — `border-radius: 0` をフレームワークのCSS変数 (Bootstrap, Material, YouTube, Reddit) を含め、すべての場所で強制。
- **動きは禁止** — すべてのトランジションとアニメーションはゼロ化される。状態変化は1995年当時のUIのように即時。
- **ホバーハイライトは完全無効** — 白いフラッシュバンの行も、灰色のティントブロックもなし:
  - 読めるすべての `:hover` CSSルールから、塗りプロパティを外科的に除去 ( `display`/`visibility`/`opacity` などの機能プロパティは維持されるので、ホバーで開くメニューは動く);
  - 読めないクロスオリジンのスタイルシートは、トランジション凍結フォールバックで無力化。
  実際のコントロール (ボタン、リンク、入力欄) だけが、テーマ化された即時のベベル応答を保持する。
- **Verdanaを100%強制** — 入力欄とtextareaを含み、フォントスムージング無効。アイコンフォントはグリフが文字に化けないよう除外。`Verdana_m1` という名前のカスタムフォント (例: デアンチエイリアスされたVerdanaパッチ) がインストールされていれば自動的に使われ、なければ通常のVerdana。
- **適応型リペインタ** — 軽量なJSスイーパーが、明るい"フラッシュバン"面とテーマ未適用のダークモード灰色をヴィンテージの茶色スケールに変換し、低コントラスト (暗い上に暗い) テキストをWCAG対応のしきい値で金色に修正。画像、動画、canvas、プレイヤーは決して触らない。
- **Shadow DOM貫通** — `attachShadow` フック経由でWebコンポーネント (YouTube、Redditなど) もテーマ化。
- **ポップアップはおとなしく** — メニュー、ダイアログ、ツールチップ、ホバーカードは再着色のみ。スクリプトは `opacity`/`z-index`/`visibility` を決して強制しないので、非表示のサイトUIは非表示のまま。
- **セーフティガード** — OAuth、キャプチャ、銀行、決済ページではスクリプトが自動無効化され、重要なフローが再スタイルされることはない。

## 対応ブラウザテーマ

デスクトップインストーラーの `browsers` ターゲットは、インストール済みおよびポータブルのChromiumプロファイルを検出し、Tampermonkeyのカバレッジを報告し、選択したブラウザテーマをステージングし、各プロファイルの正しいインストール/更新ページを開く。Chromiumはプロファイルごとに **Developer mode → Load unpacked** の確認が1回必要。インストーラーは安定版テーマパスをクリップボードにコピーする。以降のパレット変更はそのパスを再利用する。

## 既知の挙動

- ホバー効果をCSS `:hover` ではなくJavaScript (クラス切り替え) で構築するサイトは、独自のハイライトを表示し続けることがある。
- 稀なクロスオリジンCSSを持つサイトでは、フォーカス不可の要素をクリックすると、マウスが離れるまで視覚状態の変化が遅れることがある (ホバー凍結フォールバックが動作中)。実際のボタンとリンクは対象外。
- スクリプトは設計上静的: オプションパネルもサイト別トグルもない。別の味が欲しければフォークして先頭のトークンを編集しよう。

## 新バージョンのリリース (メンテナー向け)

まず `CHANGELOG.md` の先頭に `## [x.y.z] - date` のエントリを追加してください — これがないと `release.ps1` は実行を拒否します。次に:

```powershell
.\release.ps1 -Message "変更内容"
```

`@version` のパッチ番号を上げ（Tampermonkey ヘッダーと `W95_VERSION` スタンプは一緒に動く）、生成したデスクトップテーマを再構築し、リリースゲート一式を実行して、コミット・タグ・プッシュする — Tampermonkeyクライアントは自動で更新を取得。大規模リリースには `-Bump minor` か `-Bump major` を渡す。
