# Wintage

**ธีมวินเทจ Windows 95 สีทองเข้มสำหรับทั้งเว็บ.** สคริปต์ผู้ใช้ของ Tampermonkey ที่จัดสไตล์ทุกเว็บไซต์ใหม่ให้เป็นแอปพลิเคชัน Windows 95 สีน้ำตาลทองเข้ม: ขอบ 3D คมแบบพิกเซล, มุมโค้งเป็นศูนย์, แอนิเมชันเป็นศูนย์, ไม่มีแฟลชตอนโฮเวอร์, Verdana ทุกที่
[🤍 สนับสนุนผู้พัฒนา](https://buymeacoffee.com/vacuum34)

_เว็บสมัยใหม่ปรับแต่งความสวยงามโดยแลกกับความใช้งานได้ มุมโค้งแทนที่ลำดับชั้นภาพ แอนิเมชันแทนที่การตอบสนอง เงาแทนที่โครงสร้าง และความเรียบง่ายมักลบสัญญาณที่สมองของเราใช้ทำความเข้าใจอินเทอร์เฟซออกไป_

_ผู้ใช้ไม่ควรต้องเดาว่าสิ่งใดคือปุ่ม ป้าย การ์ด หรือข้อความธรรมดา Wintage นำภาษาภาพที่ชัดเจนกลับมา: ปุ่มนูน ช่องอินพุตจม ขอบคม ตัวอักษรสม่ำเสมอ ไม่มีสิ่งรบกวน และการเปลี่ยนสถานะทันที_

_ทุกองค์ประกอบสื่อถึงจุดประสงค์ของมันได้ในพริบตา ลดภาระการคิด และทำให้เว็บรู้สึกเหมือนเครื่องมือแม่นยำอีกครั้ง แทนที่จะเป็นกลุ่มฟองตกแต่ง_

## การติดตั้ง

1. ติดตั้ง [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Opera, Safari)
2. คลิก **[ติดตั้ง Wintage](https://raw.githubusercontent.com/vacterro/Wintage/main/wintage.user.js)** — Tampermonkey จะเปิดหน้าติดตั้งให้อัตโนมัติ
3. เสร็จสิ้น ทุกเว็บไซต์ที่คุณเยี่ยมชมตอนนี้กำลังรัน Windows 95 รุ่นสีทองเข้ม

## การอัปเดต

- **อัตโนมัติ:** สคริปต์มี `@updateURL`/`@downloadURL` ชี้ไปที่ repo นี้ Tampermonkey จึงดึงเวอร์ชันใหม่มาในการตรวจสอบอัปเดตตามปกติ
- **รีเฟรชด้วยมือ:** Tampermonkey → **Utilities → Check for userscript updates** หรือเพียงคลิกลิงก์ติดตั้งอีกครั้ง — มันแทนที่เวอร์ชันเก่าในตำแหน่งเดิม ไม่ต้องถอนการติดตั้ง
- **แถวธีมหายไปหมายถึงสคริปต์เก่า:** เมนูถูกสร้างจากทะเบียนธีมในตัว และการทดสอบปล่อยรุ่นต้องการแถวเมนูหนึ่งแถวพอดีสำหรับทุกพาเล็ตในตัว ถ้าเมนูสั้นกว่ารายการพาเล็ตด้านล่าง ให้คลิก **Install Wintage** อีกครั้งและยืนยัน **Update** ใน Tampermonkey

## สิบหกพาเล็ต และสวิตช์

Wintage ไม่ใช่หนึ่งพาเล็ตอีกต่อไป หกคือโครงสร้างของ UI.md เองที่หมุนไปยังตระกูลฮิวอื่น (Dark Golden, Claude Code, Antigravity, K-Lite, FreeBuff, CodeNomad), Custom แก้ไขและบันทึกได้จากตัวติดตั้งเดสก์ท็อป และเก้าพาเล็ตนำเข้าจาก [FastPrompter](https://github.com/vacterro) (Default, Golden Vintage, Golden Default, Vintage Dark, Vintage Classic, Dark 2 OLED, Dracula, Nord, Solarized Dark) ทุกพาเล็ตผ่าน WCAG AA บนสามโทเคนที่บรรทุกข้อความ — เกตการสร้างจะปฏิเสธพาเล็ตที่ไม่ผ่าน

เลือกจาก **เมนู Tampermonkey** บนหน้าใดก็ได้; ตัวเลือกถูกเก็บต่อผู้ใช้ ไม่ใช่ต่อเว็บไซต์ จึงมีผลข้ามทุกโดเมน

พาเล็ตอยู่ใน `themes/*.json` นอกสคริปต์ ด้วยเหตุผลเดียว: Tampermonkey ดาวน์โหลด `wintage.user.js` ซ้ำทุกอัปเดต พาเล็ตที่แก้ด้วยมือเข้าไปจึงจะหาย นำกลับไปใช้บนบิลด์ใหม่ด้วย:

```powershell
.\install-themes.ps1 -Latest
```

## นอกเหนือจากเบราว์เซอร์

พาเล็ตเดียวกันติดตั้งลงในแอปพลิเคชันเดสก์ท็อป — VS Code และ Antigravity เป็นธีมสี, แอป Electron (Freebuff, แอปเอเจนต์ Antigravity) ผ่าน shim ที่ฉีดสไตล์ชีตเดียวกับที่สคริปต์ผู้ใช้นี้ใช้ มี GUI เล็ก ๆ สำหรับมัน:

ดับเบิลคลิก **`Wintage Installer.vbs`** ที่รากของ repo มันเปิด GUI โดยไม่มีหน้าต่างคอนโซล ตัวเรียกใช้ `.cmd` รุ่นเก่าส่งต่อไปยังโฮสต์ที่ซ่อนเดียวกัน; `desktop\WintageInstaller.ps1` ยังรันตรง ๆ เพื่อการวินิจฉัยได้

สิ่งที่แต่ละเป้าหมายเข้าถึงได้และไม่ได้ — รวมถึงสองแอปที่ถูกปิดตายด้วยฟิวส์หรือมีสีคอมไพล์ในตัว — เขียนไว้ใน **[desktop/README.md](desktop/README.md)**

## คุณสมบัติ

- **พาเล็ต Golden Default** — ผืนผ้าใบน้ำตาลดำเข้ม `#1A1810`, ข้อความทอง `#D4C89A`, ขอบไฮไลต์ทอง `#F0D060` พื้นผิวเรียบทึบเท่านั้น: ไม่มีเกรเดียนต์, ไม่มีเบลอ, ไม่มีเอฟเฟกต์โปร่งใส
- **ขอบ 3D คลาสสิก** — ปุ่มนูน, อินพุตจม, ปุ่มที่กดแล้วจะยุบลง (พร้อมการเลื่อนป้าย 1px แบบของแท้) สกรอลล์บาร์เต็ม 16px สไตล์ Win95, ครบหัวแม่มือและปุ่มขอบ
- **นักฆ่ารัศมี** — บังคับ `border-radius: 0` ทุกที่ รวมถึงตัวแปร CSS ของเฟรมเวิร์ก (Bootstrap, Material, YouTube, Reddit)
- **ห้ามเคลื่อนไหว** — ทรานสิชันและแอนิเมชันทั้งหมดถูกทำให้เป็นศูนย์ การเปลี่ยนสถานะเกิดขึ้นทันที เหมือน UI ปี 1995 จริง
- **ปิดไฮไลต์ตอนโฮเวอร์โดยสิ้นเชิง** — ไม่มีแถวแฟลชขาว, ไม่มีบล็อกเงาสีเทา:
  - คุณสมบัติการพ่นสีถูกถอดแบบศัลยกรรมจากทุกกฎ CSS `:hover` ที่อ่านได้ (คุณสมบัติเชิงฟังก์ชันเช่น `display`/`visibility`/`opacity` ถูกเก็บไว้ เมนูที่เปิดเมื่อโฮเวอร์จึงยังทำงาน);
  - สไตล์ชีตข้ามแหล่งที่มาที่อ่านไม่ได้ถูกทำให้เป็นกลางด้วยฟอลแบ็กตรึงทรานสิชัน
  เฉพาะคอนโทรลจริง (ปุ่ม, ลิงก์, อินพุต) เท่านั้นที่ยังได้การตอบสนองขอบธีมทันที
- **บังคับ Verdana 100% ทุกที่** — รวมถึงอินพุตและ textarea, โดยปิดการปรับขอบฟอนต์ ฟอนต์ไอคอนถูกยกเว้นเพื่อไม่ให้กลายเป็นตัวอักษร หากคุณมีฟอนต์กำหนดเองที่ติดตั้งในชื่อ `Verdana_m1` (เช่น แพตช์ Verdana ไร้แอนตี้อะไลแอส) มันจะถูกใช้โดยอัตโนมัติ; มิฉะนั้นใช้ Verdana ธรรมดา
- **ตัวทาสีซ้ำแบบปรับตัว** — สวีปเปอร์ JS น้ำหนักเบาแปลงพื้นผิว "แฟลชแบงก์" สว่างและเทาโหมดมืดไร้ธีมให้เป็นสเกลน้ำตาลวินเทจ และแก้ข้อความคอนทราสต์ต่ำ (มืดบนมืด) เป็นสีทอง ตามเกณฑ์ที่รับรู้ WCAG รูปภาพ วิดีโอ canvas และเพลเยอร์จะไม่ถูกแตะต้องเลย
- **ทะลุ Shadow DOM** — ทำธีมเว็บคอมโพเนนต์ด้วย (YouTube, Reddit และอื่น ๆ) ผ่านฮุค `attachShadow`
- **ป็อปอัปประพฤติตัว** — เมนู ไดอะล็อก ทูลทิป และการ์ดโฮเวอร์ถูกเปลี่ยนสีเท่านั้น; สคริปต์ไม่บังคับ `opacity`/`z-index`/`visibility` UI เว็บที่ซ่อนจึงยังคงซ่อน
- **การ์ดความปลอดภัย** — สคริปต์ปิดตัวเองบนหน้า OAuth, captcha, ธนาคาร และการชำระเงิน เพื่อให้โฟลว์สำคัญไม่ถูกจัดสไตล์ใหม่

## ธีมเบราว์เซอร์ที่เข้ากัน

เป้าหมาย `browsers` ของตัวติดตั้งเดสก์ท็อปตรวจจับโปรไฟล์ Chromium ที่ติดตั้งและพกพา รายงานความครอบคลุมของ Tampermonkey จัดธีมเบราว์เซอร์ที่เลือก และเปิดหน้าติดตั้ง/อัปเดตที่ถูกต้องสำหรับทุกโปรไฟล์ Chromium ต้องการการยืนยัน **Developer mode → Load unpacked** หนึ่งครั้งต่อโปรไฟล์; ตัวติดตั้งคัดลอกพาธธีมคงที่ไปยังคลิปบอร์ด การเปลี่ยนพาเล็ตทีหลังจะใช้พาธนั้นซ้ำ

## พฤติกรรมที่ทราบ

- เว็บไซต์ที่สร้างเอฟเฟกต์โฮเวอร์ใน JavaScript (การสลับคลาส) แทน CSS `:hover` อาจยังแสดงไฮไลต์ของตัวเอง
- บนเว็บไซต์ไม่กี่แห่งที่ CSS เป็นข้ามแหล่งที่มา การคลิกองค์ประกอบที่โฟกัสไม่ได้อาจเลื่อนการเปลี่ยนสถานะภาพจนกว่าหนูจะออก (ฟอลแบ็กตรึงโฮเวอร์ทำงานอยู่) ปุ่มและลิงก์จริงเป็นข้อยกเว้น
- สคริปต์เป็นแบบคงที่โดยการออกแบบ: ไม่มีแผงตัวเลือก, ไม่มีสวิตช์ต่อเว็บไซต์ ฟอร์กมันและแก้โทเคนบนสุดถ้าต้องการรสชาติอื่น

## การปล่อยเวอร์ชันใหม่ (สำหรับผู้ดูแล)

เพิ่มรายการ `## [x.y.z] - date` ที่ด้านบนของ `CHANGELOG.md` ก่อน — หากไม่มี `release.ps1` จะปฏิเสธไม่ให้ทำงาน จากนั้นรัน:

```powershell
.\release.ps1 -Message "what changed"
```

มันเพิ่มเลขแพตช์ `@version` (ส่วนหัว Tampermonkey และสแตมป์ `W95_VERSION` เคลื่อนไปด้วยกัน) สร้างธีมเดสก์ท็อปที่สร้างแล้วใหม่ เรียกใช้ชุดเกตการปล่อยทั้งหมด แล้ว commit, tag แล้ว push — ลูกค้า Tampermonkey ดึงอัปเดตโดยอัตโนมัติ ส่ง `-Bump minor` หรือ `-Bump major` สำหรับรุ่นที่ใหญ่กว่า
