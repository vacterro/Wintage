Vintage Win 95 Dark Golden — tema del browser (Cent Browser / Chrome / Edge)
============================================================================

Tema compagno dello userscript Wintage (https://github.com/vacterro/Wintage).
Questo tema è una palette Dark Golden fissa e legacy, inclusa manualmente e indipendente
dalle palette commutabili dello userscript: canvas #1A0F05, barra strumenti #2A1C0A, testo dorato
#D4B87A, oro degli smussi #C0A060, omnibox incassata #0F0A04, accent link #9DD9F9. Non segue
né il default dello script (Golden Default) né i pack themes/*.json: resta
sull'aspetto Dark Golden classico con cui questo tema del browser è stato realizzato.

INSTALLAZIONE:
  1. Apri chrome://extensions
  2. Attiva "Developer mode" (in alto a destra)
  3. Clicca "Load unpacked" e seleziona questa cartella (vintage_theme)
  4. Il tema si applica immediatamente. Ricaricalo allo stesso modo dopo le modifiche.

RIPRISTINO:
  Settings -> Appearance -> "Reset to default", oppure rimuovi il tema
  da chrome://extensions.

Mapping dei token:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
