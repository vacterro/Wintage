Vintage Win 95 Dark Golden — ธีมเบราว์เซอร์ (Cent Browser / Chrome / Edge)
==========================================================================

ธีมคู่หูสำหรับสคริปต์ผู้ใช้ Wintage (https://github.com/vacterro/Wintage).
ธีมนี้เป็นพาเล็ต Dark Golden แบบคงที่แบบเลกาซี บรรจุด้วยมือและเป็นอิสระจาก
พาเล็ตที่สลับได้ของสคริปต์ผู้ใช้: canvas #1A0F05, toolbar #2A1C0A, ข้อความทอง #D4B87A,
ขอบทอง #C0A060, omnibox จม #0F0A04, ลิงก์เน้น #9DD9F9. ไม่ติดตามค่าเริ่มต้นของสคริปต์
(Golden Default) หรือชุด themes/*.json — คงลุค Dark Golden แบบคลาสสิกที่ธีมเบราว์เซอร์นี้สร้างขึ้น

INSTALL:
  1. เปิด chrome://extensions
  2. เปิด "Developer mode" (มุมขวาบน)
  3. คลิก "Load unpacked" และเลือกโฟลเดอร์นี้ (vintage_theme)
  4. ธีมใช้ทันที โหลดใหม่ด้วยวิธีเดียวกันหลังแก้ไข

REVERT:
  Settings -> Appearance -> "Reset to default", หรือลบธีม
  จาก chrome://extensions.

การแมปโทเคน:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
