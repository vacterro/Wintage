# Wintage

**Винтажная тема Windows 95 «Тёмное золото» для всего веба.** Tampermonkey-юзерскрипт,
который перекрашивает любой сайт в тёмное золотисто-коричневое приложение Windows 95:
чёткие 3D-фаски, ни одного скруглённого угла, ни одной анимации, никаких
«вспышек» при наведении, везде Verdana.

_Современный веб оптимизирует эстетику в ущерб удобству. Скруглённые углы заменяют
визуальную иерархию, анимации — обратную связь, тени — структуру, а минимализм
часто убирает те самые подсказки, по которым мозг понимает интерфейс._

_Пользователь не должен гадать, что перед ним: кнопка, подпись, карточка или
просто текст. Wintage возвращает явный визуальный язык: выпуклые кнопки, утопленные
поля ввода, резкие границы, единая типографика, ноль отвлечений и мгновенная смена
состояний._

_Каждый элемент с первого взгляда говорит, зачем он нужен. Это снижает когнитивную
нагрузку и снова делает веб точным инструментом, а не коллекцией декоративных
пузырей._

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Opera, Safari).
2. Нажмите **[Установить Wintage](https://raw.githubusercontent.com/vacterro/Wintage/main/wintage.user.js)** — Tampermonkey сам откроет страницу установки.
3. Готово. Каждый сайт, который вы посещаете, теперь работает на Windows 95 в тёмной золотой редакции.

## Обновление

- **Автоматически:** скрипт несёт `@updateURL`/`@downloadURL`, указывающие на этот репозиторий, поэтому Tampermonkey подхватывает новые версии при обычных проверках обновлений.
- **Вручную:** Tampermonkey → **Utilities → Check for userscript updates**, или просто нажмите ссылку установки ещё раз — она заменит старую версию на месте, удалять ничего не нужно.
- **Пропали пункты меню тем — значит, скрипт старый:** меню строится из встроенного реестра тем, и релизный тест требует ровно один пункт меню на каждую встроенную палитру. Если пунктов меньше, чем палитр в списке ниже, снова нажмите **Install Wintage** и подтвердите **Update** в Tampermonkey.

## Шестнадцать палитр и переключатель

Wintage — это больше не одна палитра. Шесть — это собственная структура UI.md,
повёрнутая в другое семейство оттенков (Dark Golden, Claude Code, Antigravity,
K-Lite, FreeBuff, CodeNomad); Custom можно редактировать и сохранять из
десктопного установщика; девять импортированы из
[FastPrompter](https://github.com/vacterro) (Default, Golden Vintage, Golden
Default, Vintage Dark, Vintage Classic, Dark 2 OLED, Dracula, Nord, Solarized
Dark). Каждая из них проходит WCAG AA по трём токенам, которые несут текст —
сборочный шлюз не пропускает палитру, которая не проходит.

Выберите тему в **меню Tampermonkey** на любой странице; выбор хранится на
пользователя, а не на сайт, поэтому действует на всех доменах.

Палитры лежат в `themes/*.json`, вне скрипта, по одной причине: Tampermonkey
скачивает `wintage.user.js` заново при каждом обновлении, и палитра, вписанная
в него вручную, исчезнет. Заново нанесите их на свежую сборку командой:

```powershell
.\install-themes.ps1 -Latest
```

## За пределами браузера

Те же палитры ставятся в десктопные приложения — VS Code и Antigravity как цветовые
темы, Electron-приложения (Freebuff, приложение-агент Antigravity) через шим,
который внедряет ровно ту таблицу стилей, что использует юзерскрипт. Для этого есть
небольшой GUI:

Дважды щёлкните **`Wintage Installer.vbs`** в корне репозитория. Он открывает GUI
без окна консоли. Устаревший запускатель `.cmd` ведёт в тот же скрытый хост;
`desktop\WintageInstaller.ps1` по-прежнему можно запускать напрямую для диагностики.

Что каждый таргет может и не может достать — включая два приложения, которые
запаяны намертво или чьи цвета вкомпилированы, — описано в
**[desktop/README.md](desktop/README.md)**.

## Возможности

- **Палитра Golden Default** — глубокий коричнево-чёрный холст `#1A0F05`, золотой
  текст `#D4B87A`, золотые фаски `#C0A060`. Только сплошные плоские поверхности:
  ни градиентов, ни размытия, ни прозрачности.
- **Классические 3D-фаски** — кнопки выпуклые, поля ввода утоплены, нажатая кнопка
  вдавливается (с аутентичным сдвигом подписи на 1px). Скроллбары — полноценные
  16px в стиле Win95, с фасочным бегунком и стрелками.
- **Убийца радиусов** — `border-radius: 0` принудительно везде, включая CSS-переменные
  фреймворков (Bootstrap, Material, YouTube, Reddit).
- **Движение запрещено** — все переходы и анимации обнулены. Состояния меняются
  мгновенно, как в настоящем интерфейсе 1995 года.
- **Подсветка при наведении полностью отключена** — никаких белых вспышек строк и
  серых блоков:
  - свойства заливки хирургически вырезаются из каждого читаемого CSS-правила
    `:hover` (функциональные свойства вроде `display`/`visibility`/`opacity`
    сохраняются, поэтому меню, открывающиеся по наведению, продолжают работать);
  - нечитаемые кросс-доменные таблицы стилей нейтрализуются запасным вариантом
    «заморозки переходов».
  Только настоящие контролы (кнопки, ссылки, поля ввода) сохраняют мгновенный
  тематический отклик фасок.
- **Verdana принудительно везде** — включая поля ввода и textarea, со сглаживанием
  шрифта отключено. Иконочные шрифты исключены, чтобы глифы не превращались в
  буквы. Если у вас установлен шрифт с именем `Verdana_m1` (например, патч Verdana
  без сглаживания), он используется автоматически; иначе обычная Verdana.
- **Адаптивный перекрашиватель** — лёгкий JS-проходчик превращает светлые
  «вспышечные» поверхности и нетематические серые тёмных режимов в винтажную
  коричневую гамму и чинит низкоконтрастный (тёмный-на-тёмном) текст до золотого,
  по порогам с учётом WCAG. Изображения, видео, канвасы и плееры не трогаются
  никогда.
- **Проникновение в Shadow DOM** — темизирует и веб-компоненты (YouTube, Reddit и
  компанию) через перехват `attachShadow`.
- **Всплывашки ведут себя прилично** — меню, диалоги, тултипы и ховеркарды только
  перекрашиваются; скрипт никогда не принуждает `opacity`/`z-index`/`visibility`,
  поэтому скрытый UI сайта остаётся скрытым.
- **Предохранитель** — скрипт сам отключается на страницах OAuth, капчи, банков и
  платежей, чтобы критичные сценарии никогда не перекрашивались.

## Палитра

В таблице ниже показаны 10 из 21 токена палитры Golden Default. Каждая
поставляемая палитра определяет все 21; остальные 11 включают структуру
рамок, вторичный текст, семантические цвета (успех/предупреждение/опасность),

| Токен | Hex | Используется для |
|---|---|---|
| Canvas | `#1A0F05` | самый внешний фон |
| Soft | `#1E1408` | фон тела / контента |
| Surface | `#2A1C0A` | шапки, навигация, панели |
| Raised | `#362812` | кнопки, попапы, бегунок скроллбара |
| Alt | `#3A2A15` | наведение на кнопку |
| Bevel highlight | `#C0A060` | верхне-левые 3D-грани |
| Bevel shadow | `#0E0803` | нижне-правые 3D-грани |
| Text | `#D4B87A` | основной золотой текст |
| Muted | `#7A6838` | плейсхолдеры, выключенное |
| Accent | `#9DD9F9` | ссылки, фокус |

## Совместимая тема браузера

Таргет `browsers` десктопного установщика находит установленные и портативные
профили Chromium, сообщает о покрытии Tampermonkey, готовит выбранную тему браузера
и открывает правильные страницы установки/обновления для каждого профиля. Chromium
требует одно подтверждение **Developer mode → Load unpacked** на профиль;
установщик копирует стабильный путь темы в буфер обмена. Дальнейшие смены палитры
переиспользуют этот путь.

## Известные особенности

- Сайты, которые строят эффекты наведения в JavaScript (переключением классов), а
  не CSS `:hover`, могут всё ещё показывать свою подсветку.
- На редких сайтах с кросс-доменным CSS клик по нефокусируемому элементу может
  задерживать смену визуального состояния до ухода мыши (работает запасной вариант
  «заморозки наведения»). Настоящие кнопки и ссылки исключены.
- Скрипт статичен по замыслу: никакой панели настроек, никаких переключателей по
  сайтам. Форкните его и отредактируйте токены вверху, если хотите другой вкус.

## Релиз новой версии (для сопровождающих)

Отредактируйте `wintage.user.js`, затем выполните:

```powershell
.\release.ps1 -Message "что изменилось"
```

Он поднимает патч-номер `@version`, коммитит и пушит — клиенты Tampermonkey
подхватывают обновление автоматически. Передайте `-Bump minor` или `-Bump major`
для крупных релизов.
