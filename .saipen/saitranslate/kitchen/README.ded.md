# Wintage

Тьфу. Винтажная тема Windows 95 «Тёмное золото» для всего веба. Tampermonkey-
скрипт, который любую хрень в браузере превращает в тёмное золотисто-коричневое
окно Windows 95: резкие 3D-фаски, ни одного скруглённого угла, ни одной
анимации, без этих ваших «вспышек» при наведении, везде Verdana.

Современный веб продаёт красоту, а не удобство. Скруглили углы — иерархия
потерялась. Анимации — вместо ответа. Тени — вместо структуры. Минимализм выкинул
все подсказки, по которым мозг понимает, что на экране.

Человек не должен гадать: кнопка это, подпись, карточка или просто текст. Wintage
возвращает нормальный визуальный язык: кнопки торчат, поля утоплены, границы
резкие, шрифт один, отвлечений ноль, состояние меняется мгновенно.

Каждый элемент сразу говорит, зачем он. Меньше мозг грузим — веб снова точный
инструмент, а не куча декоративных пузырей.

## Установка

1. Ставь [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Opera, Safari).
2. Жми **[Установить Wintage](https://raw.githubusercontent.com/vacterro/Wintage/main/wintage.user.js)** — Tampermonkey сам откроет страницу.
3. Всё. Любой сайт теперь — Windows 95, тёмная золотая редакция.

## Обновление

- **Само:** скрипт несёт `@updateURL`/`@downloadURL` на этот репозиторий —
  Tampermonkey подхватит новые версии при своих проверках.
- **Руками:** Tampermonkey → **Utilities → Check for userscript updates**, или
  просто жми ссылку установки ещё раз — заменит старую версию на месте.
- **Пропали пункты тем — скрипт старый:** меню собирается из встроенного реестра
  тем, релизный тест требует ровно один пункт на каждую палитру. Пунктов меньше,
  чем палитр в списке ниже? Жми **Install Wintage** заново и подтверждай
  **Update**.

## Шестнадцать палитр и переключатель

Wintage — давно не одна палитра. Шесть — это собственная структура UI.md,
повёрнутая в другое семейство оттенков (Dark Golden, Claude Code, Antigravity,
K-Lite, FreeBuff, CodeNomad); Custom правится и сохраняется из десктопного
установщика; девять импортированы из [FastPrompter](https://github.com/vacterro)
(Default, Golden Vintage, Golden Default, Vintage Dark, Vintage Classic, Dark 2
OLED, Dracula, Nord, Solarized Dark). Каждая проходит WCAG AA по трём токенам,
что несут текст — сборочный шлюз не пропустит палитру, которая не проходит.

Выбирай в **меню Tampermonkey** на любой странице; выбор хранится на
пользователя, не на сайт, значит действует на всех доменах.

Палитры лежат в `themes/*.json`, вне скрипта. Зачем? Tampermonkey качает
`wintage.user.js` заново при каждом обновлении — вписанная руками палитра просто
исчезнет. Нанеси их на свежую сборку:

```powershell
.\install-themes.ps1 -Latest
```

## За пределами браузера

Те же палитры ставятся в десктопные приложения — VS Code и Antigravity как
цветовые темы, Electron-приложения (Freebuff, агент Antigravity) через шим,
который вставляет ровно ту таблицу стилей, что юзерскрипт. Есть маленький GUI:

Дважды щёлкни **`Wintage Installer.vbs`** в корне репозитория — GUI откроется без
окна консоли. Старый `.cmd` ведёт в тот же скрытый хост; `desktop\WintageInstaller.ps1`
можно гонять напрямую для диагностики.

Что каждый таргет может и не может достать — включая два приложения, которые
запаяны намертво или цвета которых вкомпилированы, — написано в
**[desktop/README.md](desktop/README.md)**.

## Возможности

- **Тёмная золотая палитра** — глубокий коричнево-чёрный холст `#1A0F05`,
  золотой текст `#D4B87A`, золотые фаски `#C0A060`. Только плоские поверхности:
  без градиентов, без размытия, без прозрачности.
- **Классические 3D-фаски** — кнопки торчат, поля утоплены, нажатая кнопка
  вдавливается (с честным сдвигом подписи на 1px). Скроллбары — полные 16px
  в стиле Win95, с фасочным бегунком и стрелками.
- **Убийца радиусов** — `border-radius: 0` принудительно везде, включая
  CSS-переменные фреймворков (Bootstrap, Material, YouTube, Reddit).
- **Движение запрещено** — все переходы и анимации обнулены. Состояния меняются
  мгновенно, как в настоящем 1995-м.
- **Подсветка при наведении отключена полностью** — ни белых вспышек, ни серых
  блоков:
  - свойства заливки хирургически вырезаются из каждого читаемого правила
    `:hover` (функциональное вроде `display`/`visibility`/`opacity` остаётся —
    меню, открывающиеся по наведению, работают);
  - нечитаемые кросс-доменные стили нейтрализуются запасным вариантом
    «заморозки переходов».
  Только настоящие контролы (кнопки, ссылки, поля ввода) отвечают мгновенной
  тематической фаской.
- **Verdana принудительно везде** — включая поля ввода и textarea, со
  сглаживанием шрифта отключено. Иконочные шрифты исключены — глифы не должны
  превращаться в буквы. Есть шрифт `Verdana_m1` (например, патч Verdana без
  сглаживания)? Он используется автоматически. Нет — обычная Verdana.
- **Адаптивный перекрашиватель** — лёгкий JS-проходчик переводит светлые
  «вспышечные» поверхности и серые тёмных режимов в винтажную коричневую гамму,
  чинит низкоконтрастный (тёмный-на-тёмном) текст до золотого, по порогам
  с учётом WCAG. Изображения, видео, канвасы и плееры не трогает никогда.
- **Проникновение в Shadow DOM** — темизирует и веб-компоненты (YouTube, Reddit
  и прочих) через перехват `attachShadow`.
- **Всплывашки ведут себя прилично** — меню, диалоги, тултипы и ховеркарды
  только перекрашиваются; скрипт никогда не трогает `opacity`/`z-index`/`visibility`,
  так что скрытый UI сайта остаётся скрытым.
- **Предохранитель** — скрипт сам отключается на страницах OAuth, капчи, банков
  и платежей. Критичные сценарии не перекрашиваются. Точка.

## Совместимая тема браузера

Таргет `browsers` десктопного установщика находит установленные и портативные
профили Chromium, докладывает о покрытии Tampermonkey, готовит выбранную тему
браузера и открывает правильные страницы установки/обновления для каждого
профиля. Chromium требует одно подтверждение **Developer mode → Load unpacked**
на профиль; установщик копирует стабильный путь темы в буфер обмена. Дальнейшие
смены палитры переиспользуют этот путь.

## Известные особенности

- Сайты, которые строят эффекты наведения в JavaScript (переключением классов),
  а не CSS `:hover`, могут всё ещё показывать свою подсветку. Их не обманешь.
- На редких сайтах с кросс-доменным CSS клик по нефокусируемому элементу может
  задержать смену состояния до ухода мыши (работает «заморозка наведения»).
  Настоящие кнопки и ссылки исключены.
- Скрипт статичен по замыслу: никакой панели настроек, никаких переключателей
  по сайтам. Хочешь другой вкус — форкай и правь токены вверху.

## Релиз новой версии (для сопровождающих)

Правишь `wintage.user.js`, затем:

```powershell
.\release.ps1 -Message "что изменилось"
```

Поднимает патч-номер `@version`, коммитит и пушит — клиенты Tampermonkey
подхватят обновление сами. Для крупных релизов передавай `-Bump minor` или
`-Bump major`.
