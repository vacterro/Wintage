# Wintage

**سمة Windows 95 الذهبية الداكنة الكلاسيكية لشبكة الإنترنت بأكملها.** سكربت مستخدم لـ Tampermonkey يعيد تنسيق كل موقع إلى تطبيق Windows 95 بني ذهبي داكن: حواف ثلاثية الأبعاد حادة البكسلات، صفر زوايا مستديرة، صفر حركات، بلا ومضات عند التحويم، و Verdana في كل مكان.

_الويب الحديث يحسّن الجماليات على حساب سهولة الاستخدام. الزوايا المستديرة تحل محل التدرج البصري، والحركات تحل محل التغذية الراجعة، والظلال تحل محل البنية، والبساطة غالباً ما تزيل الإشارات التي يعتمد عليها دماغنا لفهم الواجهة._

_لا ينبغي للمستخدم أن يخمّن هل الشيء زر أم تسمية أم بطاقة أم مجرد نص. يعيد Wintage اللغة البصرية الواضحة: أزرار بارزة، حقول إدخال غائرة، حدود حادة، خطوط متناسقة، صفر مشتتات، وتغيّر فوري للحالة._

_كل عنصر يخبر عن الغرض منه بنظرة واحدة، مما يقلل الحمل المعرفي ويجعل الويب أداة دقيقة مجدداً بدلاً من مجموعة فقاعات زخرفية._

## التثبيت

1. ثبّت [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Opera, Safari).
2. اضغط **[ثبّت Wintage](https://raw.githubusercontent.com/vacterro/Wintage/main/wintage.user.js)** — يفتح Tampermonkey صفحة التثبيت تلقائياً.
3. انتهى. كل موقع تزوره يعمل الآن بنظام Windows 95، إصدار الذهبي الداكن.

## التحديث

- **تلقائياً:** يحمل السكربت `@updateURL`/`@downloadURL` يشيران إلى هذا المستودع، فيلتقط Tampermonkey النسخ الجديدة في فحوصات التحديث الدورية.
- **تحديث يدوي:** Tampermonkey → **Utilities → Check for userscript updates**، أو فقط اضغط رابط التثبيت مجدداً — يستبدل النسخة القديمة في مكانها، دون حاجة لإلغاء التثبيت.
- **صفوف السمات المفقودة تعني سكربت قديماً:** تُنشأ القائمة من سجل السمة المدمج، ويتطلب اختبار الإصدار صف قائمة واحداً بالضبط لكل لوحة ألوان مدمجة. إذا كانت القائمة أقصر من قائمة اللوحات أدناه، اضغط **Install Wintage** مجدداً وأكّد **Update** في Tampermonkey.

## ست عشرة لوحة ألوان، ومفتاح تحويل

لم يعد Wintage لوحة واحدة. ستٌّ هي بنية UI.md نفسها مُدارة إلى عائلة درجات لونية أخرى (Dark Golden, Claude Code, Antigravity, K-Lite, FreeBuff, CodeNomad)، ويمكن تحرير Custom وحفظه من مثبّت سطح المكتب، وتسعٌ مستوردة من [FastPrompter](https://github.com/vacterro) (Default, Golden Vintage, Golden Default, Vintage Dark, Vintage Classic, Dark 2 OLED, Dracula, Nord, Solarized Dark). كل واحدة منها تجتاز WCAG AA على الرموز الثلاثة التي تحمل نصاً — بوابة البناء ترفض أي لوحة لا تفعل ذلك.

اختر واحدة من **قائمة Tampermonkey** في أي صفحة؛ يُخزَّن الاختيار لكل مستخدم لا لكل موقع، فيبقى سارياً عبر كل النطاقات.

تعيش اللوحات في `themes/*.json`، خارج السكربت، لسبب واحد: يعيد Tampermonkey تنزيل `wintage.user.js` في كل تحديث، لذا أي لوحة تُحرَّر يدوياً داخله ستختفي. أعد تطبيقها على بناء جديد بالكامل بهذا الأمر:

```powershell
.\install-themes.ps1 -Latest
```

## ما وراء المتصفح

اللوحات نفسها تُثبَّت في تطبيقات سطح المكتب — VS Code و Antigravity كسمات ألوان، وتطبيقات Electron (Freebuff، تطبيق وكيل Antigravity) عبر shim يحقن ورقة الأنماط ذاتها التي يستخدمها هذا السكربت. توجد واجهة رسومية صغيرة لذلك:

انقر نقراً مزدوجاً على **`Wintage Installer.vbs`** في جذر المستودع. يفتح الواجهة دون نافذة طرفية. مُشغِّل `.cmd` القديم يمرر إلى نفس المضيف المخفي؛ وما زال بإمكانك تشغيل `desktop\WintageInstaller.ps1` مباشرة للتشخيص.

ما يمكن لكل هدف الوصول إليه وما لا يمكن — بما فيه التطبيقان الملحومان أو ذوا الألوان المضمّنة — مكتوب في **[desktop/README.md](desktop/README.md)**.

## الميزات

- **لوحة Golden Default** — خلفية بنية سوداء عميقة `#1A1810`، نص ذهبي `#D4C89A`، حواف بارزة ذهبية `#F0D060`. أسطح مستوية صلبة فقط: لا تدرجات، لا ضبابية، لا تأثيرات شفافية.
- **حواف ثلاثية الأبعاد كلاسيكية** — الأزرار بارزة، حقول الإدخال غائرة، والزر المضغوط ينضغط للداخل (مع إزاحة التسمية الأصلية 1px). أشرطة التمرير بعرض 16px كامل بأسلوب Win95، بمقبض وأزرار ذات حواف.
- **قاتل نصف القطر** — فرض `border-radius: 0` في كل مكان، بما فيه متغيرات CSS الخاصة بأطر العمل (Bootstrap, Material, YouTube, Reddit).
- **الحركة ممنوعة** — جميع التحولات والحركات تُصفَّر. تغيّر الحالة فوري، كواجهة حقيقية من 1995.
- **تعطيل تمييز التحويم تماماً** — لا صفوف وميض بيضاء، لا كتل تظليل رمادية:
  - تُنتزع خصائص التلوين جراحياً من كل قاعدة CSS `:hover` مقروءة (تُبقي الخصائص الوظيفية مثل `display`/`visibility`/`opacity`، فتبقى القوائم المفتوحة بالتحويم تعمل)؛
  - تُعادل أوراق الأنماط عبر النطاقات غير المقروءة بآلية احتياطية لتجميد الانتقالات.
  فقط عناصر التحكم الحقيقية (الأزرار، الروابط، حقول الإدخال) تحتفظ باستجابة حواف فورية وفق السمة.
- **فرض Verdana 100% في كل مكان** — بما فيه حقول الإدخال ومناطق النص، مع تعطيل تنعيم الخطوط. تُستثنى خطوط الأيقونات حتى لا تتحول رموزها إلى حروف. إذا كان لديك خط مخصص مثبّت باسم `Verdana_m1` (مثل رقعة Verdana منزوعة الأنترلياسنغ)، يُستخدم تلقائياً؛ وإلا فـ Verdana العادية.
- **معيد الطلاء التكيفي** — ماسح JavaScript خفيف يحوّل الأسطح الفاتحة "الومّاضة" والرمادية الداكنة غير المنسقة إلى مقياس بني كلاسيكي، ويصحح النص منخفض التباين (داكن على داكن) إلى الذهبي، عند عتبات واعية بـ WCAG. الصور والفيديو واللوحات القماشية والمشغلات لا تُلمَس أبداً.
- **اختراق Shadow DOM** — ينسق مكوّنات الويب أيضاً (YouTube, Reddit وأصدقاء) عبر خطاف `attachShadow`.
- **النوافذ المنبثقة حسنة التصرف** — القوائم والحوارات وتلميحات الأدوات وبطاقات التحويم يُعاد تلوينها فقط؛ السكربت لا يفرض أبداً `opacity`/`z-index`/`visibility`، لذا تبقى واجهات المواقع المخفية مخفية.
- **حارس أمان** — يعطّل السكربت نفسه على صفحات OAuth وcaptcha والخدمات المصرفية والدفع حتى لا تُعاد تنسيق المسارات الحرجة أبداً.

## لوحة الألوان

الجدول أدناه يعرض 10 من 21 رمزاً للوحة Golden Default. كل لوحة مشحونة تُعرّف الرموز الـ 21 كلها؛ والـ 11 الباقية تغطي بنية الحواف، النص الثانوي، الألوان الدلالية (نجاح/تحذير/خطر)، التحديد، وتفاصيل خاصة بكل هدف.

| Token | Hex | يُستخدم لـ |
|---|---|---|
| background | `#1A1810` | الخلفية الخارجية القصوى |
| backgroundSoft | `#232018` | خلفية الجسم / المحتوى |
| surface | `#332E22` | الترويسات، شريط التنقل، الألواح |
| surfaceRaised | `#3D372A` | الأزرار، النوافذ المنبثقة، مقبض شريط التمرير |
| surfaceAlt | `#453D30` | تحويم الزر |
| borderHighlight | `#F0D060` | الحواف ثلاثية الأبعاد أعلى-يسار |
| borderDark | `#100E08` | الحواف ثلاثية الأبعاد أسفل-يمين |
| textPrimary | `#D4C89A` | النص الذهبي الأساسي |
| textMuted | `#6E674E` | النص البديل، المعطّل |
| link | `#F0D060` | الروابط، التركيز |

## سمة متصفح مطابقة

هدف `browsers` في مثبّت سطح المكتب يكتشف ملفات تعريف Chromium المثبتة والمحمولة، ويبلّغ عن تغطية Tampermonkey، ويجهّز سمة المتصفح المختارة، ويفتح صفحات التثبيت/التحديث الصحيحة لكل ملف تعريف. يتطلب Chromium تأكيد **Developer mode → Load unpacked** واحداً لكل ملف تعريف؛ ينسخ المثبّت مسار السمة الثابت إلى الحافظة. تغييرات اللوحات اللاحقة تعيد استخدام ذلك المسار.

## سلوكيات معروفة

- المواقع التي تبني تأثيرات التحويم في JavaScript (تبديل الفئات) بدلاً من CSS `:hover` قد تظهر تمييزها الخاص.
- في المواقع النادرة التي يكون CSS فيها عبر النطاقات، قد يؤخر النقر على عنصر غير قابل للتركيز تغيّر حالته البصرية حتى يغادر الماوس (آلية تجميد التحويم الاحتياطية تعمل). الأزرار والروابط الحقيقية مستثناة.
- السكربت ثابت بالتصميم: لا لوحة خيارات، لا مفاتيح لكل موقع. انسخه فرعاً وعدّل الرموز في الأعلى إذا أردت نكهة مختلفة.

## إصدار نسخة جديدة (للمشرفين)

أضف إدخالاً بالصيغة `## [x.y.z] - date` إلى أعلى `CHANGELOG.md` أولاً — لن يعمل `release.ps1` بدونه. ثم:

```powershell
.\release.ps1 -Message "what changed"
```

يرفع رقم رقعة `@version` (رأس Tampermonkey وطابع `W95_VERSION` يتحركان معاً)، ويعيد بناء السمات المكتبية المُولَّدة، ويشغّل كامل مجموعة بوابات الإصدار، ويلتزم، ويوسم، ويرفع — يلتقط عملاء Tampermonkey التحديث تلقائياً. مرّر `-Bump minor` أو `-Bump major` للإصدارات الأكبر.
