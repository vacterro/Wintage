# ADR-010 — Reddit is a high-churn host and runs the lean CSS-only path

Date: 2026-10-05. Ticket T-902 (SRC-065).

## Context

Users reported Chromium/Brave tab crashes on Reddit with `STATUS_ACCESS_VIOLATION`
while Wintage was installed. That code is a **native renderer fault** — a
userscript's JavaScript cannot raise an access violation — so nothing in this
repository claims Wintage owns the native fault. What the reports did establish
is that the crash window coincided with the document-wide repainter running on a
page shape it was never designed for: Reddit is an infinite feed of `shreddit-*`
web components that appends posts, comments and media shells faster than a
document-wide sweep can settle. On that page the repainter's cost profile is the
worst case of every mechanism Wintage has: a body-subtree `MutationObserver`,
`getComputedStyle` sweeps of newly created subtrees, per-shadow-root observers,
CSSOM `:hover` surgery over readable stylesheets, and repeated force passes over
a DOM that never stops growing.

The tempting fix was a second, Reddit-only mode. That would have duplicated the
gate that already exists: `HIGH_CHURN_HOST` was already the single authority
deciding whether the repainter starts at all, and `CSS_ONLY_MODE` was already
derived from it — a Reddit-only branch would have been a second place to keep in
sync, and the next agent would have had to know both.

## Decision

Reddit joins the existing contract, as one term on the existing line:

```js
const HIGH_CHURN_HOST = IS_X || IS_CHATGPT || IS_REDDIT || /(^|\.)(claude\.ai|gemini\.google\.com|chat\.qwen\.ai|perplexity\.ai)$/.test(HOST);
const CSS_ONLY_MODE = HIGH_CHURN_HOST;
```

Every expensive mechanism in the userscript already keys off `CSS_ONLY_MODE`, so
this one line (plus bounded CSS for the surfaces the repainter used to correct by
hand) is the whole change:

- no document-wide repaint `MutationObserver` (`startObservers` returns early),
- no generic `getComputedStyle` sweep and no force passes (`repainterSuspended`,
  `startSweeping` takes the CSS-only branch),
- no CSSOM `:hover` surgery (the `CSSStyleSheet` instrumentation block is
  skipped),
- no per-shadow-root repaint observer (`pierceShadow` injects the stylesheet and
  stops).

Shadow DOM is **not** disabled on Reddit. The `attachShadow` hook still injects
the bounded creation-time stylesheet into each new root, because `shreddit-*`
components live there and a root with no stylesheet is an unthemed root.
Creation-time injection is bounded (one `<style>` per root, no observer, no
recursion into descendants); continuous JS repainting inside shadow roots is
what stays off.

## Consequences

- Reddit's visual correction is now CSS. Any surface that still looks wrong is
  fixed in the `html[data-w95-reddit="1"]` block with a **stable semantic
  selector** — named custom element, ARIA role, stable data attribute or id.
  `[class*=...]`, `:has()`, generated atomic classes and build hashes are
  rejected by `tools/test-reddit-cssonly.js` for the T-902 rule group, because a
  selector that tracks Reddit's build output dies silently in one deploy and the
  repair that then presents itself is "turn the repainter back on".
- **Do not remove `IS_REDDIT` from `HIGH_CHURN_HOST` to chase a cosmetic gap.**
  That reinstates the crash-window machinery on the one host that must not have
  it. Fix the CSS, and bring performance evidence plus a new acceptance gate if
  the repainter is ever proposed for Reddit again.
- `window.__wintageDiag()` exposes `redditCssOnly`, `repaintSkippedHighChurn`
  and `shadowCssInjected` so the decision is observable in a live page without
  any noisy UI or telemetry.
- The lean path fails open, not closed: if Reddit's DOM changes, the CSS stops
  matching and a surface degrades visually. Wintage keeps running. Trading
  renderer stability for cosmetic coverage on this host is the one trade this ADR
  forbids.
- Cosmetic coverage on Reddit is expected to be slightly worse than on a
  repainted host. That degradation is intentional and is the price of the
  stability contract; it is not a bug to be repaired by re-enabling the
  repainter.
