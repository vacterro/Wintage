# ADR-011 — Surviving strict host CSP and framework hydration in CSS-only mode

Date: 2026-10-07. Scope: Host resilience, CSP bypass via adoptedStyleSheets, and root attribute persistence under React hydration.

## Context

On high-churn and heavily protected hosts like ChatGPT (`chatgpt.com`), Wintage appeared completely inert — the page remained in stock dark theme, with no vintage styling, 3D borders, or Verdana font applied.

Live debugging directly inside the browser session revealed three distinct compounding failure points:

1. **Host Content Security Policy (CSP)**:
   ChatGPT serves a strict CSP directive `default-src 'none'`. When userscripts (particularly in `@sandbox raw` or direct document context) attempt to inject CSS by creating a `<style>` element and setting `style.textContent`, the browser engine blocks it:
   `Applying inline style violates CSP directive 'default-src 'none''`.
   Consequently, the global vintage stylesheet was never parsed or applied by the renderer.

2. **Framework Hydration Root Attribute Wipe**:
   Wintage applies initial background and scoping attributes (`data-w95-chatgpt="1"`, `data-w95-dark="1"`, `data-w95-theme="golden"`) during `document-start` in `paintRoot()`.
   When modern SSR/hydration frameworks (such as Next.js/React on ChatGPT) hydrate the document, the client-side reconciler cleanses unexpected root attributes that do not match the server-rendered HTML. Because ChatGPT is flagged as `HIGH_CHURN_HOST`, `CSS_ONLY_MODE` is active (`repainterSuspended = true`), meaning no generic body mutation observer runs to re-add attributes. The page lost its scoping attribute `html[data-w95-chatgpt="1"]`, causing all scoped CSS rules to fail to match.

3. **NFE Scope Shadowing Call Stack Overflow**:
   A bootstrap wrapper written as `whenRoot(function paintRoot() { paintRoot(); })` created a Named Function Expression whose inner identifier shadowed the outer `paintRoot` function. This triggered an immediate unconditional infinite recursion:
   `RangeError: Maximum call stack size exceeded`.

## Decisions

### 1. Primary Injection via Constructable Stylesheets (`adoptedStyleSheets`)
Instead of relying exclusively on DOM `<style>` injection, stylesheet injection prefers the Constructable Stylesheet API:

```js
if (document.adoptedStyleSheets && 'replaceSync' in CSSStyleSheet.prototype) {
  try {
    const sheet = new CSSStyleSheet();
    sheet.replaceSync(css);
    document.adoptedStyleSheets = [...document.adoptedStyleSheets, sheet];
  } catch (e) { /* fallback to DOM <style> */ }
}
```

Constructable stylesheets operate directly within the CSSOM without serialized inline HTML text, bypassing `default-src 'none'` CSP barriers cleanly. This is applied both to the top-level document and to shadow roots (`attachShadow`).

### 2. Dedicated Root Attribute Guardian Observer
In `CSS_ONLY_MODE`, document-wide body sweeps are disabled for performance. However, the root `<html>` element requires persistent protection against framework hydration wipes:

```js
whenRoot(function bootstrapPaintRoot() {
  paintRoot();
  try {
    const root = document.documentElement;
    let inPaint = false;
    const rootObs = new MutationObserver(function () {
      if (inPaint) return;
      const missing = (typeof IS_CHATGPT !== 'undefined' && IS_CHATGPT && !root.hasAttribute('data-w95-chatgpt')) ||
                      (typeof IS_REDDIT !== 'undefined' && IS_REDDIT && !root.hasAttribute('data-w95-reddit')) ||
                      (typeof IS_X !== 'undefined' && IS_X && !root.hasAttribute('data-w95-x')) ||
                      !root.hasAttribute('data-w95-theme');
      if (missing) {
        inPaint = true;
        try { paintRoot(); } finally { inPaint = false; }
      }
    });
    rootObs.observe(root, { attributes: true, subtree: false });
  } catch (e) { }
});
```

Observing only `{ attributes: true, subtree: false }` on `document.documentElement` carries near-zero overhead (no subtree traversal, no DOM polling) while guaranteeing that framework reconciliation cannot strip theme markers.

### 3. Distinct Function Expression Naming
Callbacks passed to lifecycle hooks must never use an NFE matching an outer function name. The bootstrap callback is named `bootstrapPaintRoot`.

## Prevention & Future Diagnostics

When investigating reports where Wintage appears inactive on a modern web application:

1. **Check CSP & Stylesheet Status**:
   Run in the host console:
   `document.adoptedStyleSheets.length` and `document.querySelectorAll('style[data-w95]').length`.
   If `adoptedStyleSheets` contains the sheet, CSS is alive even if `<style>` elements were blocked by CSP.

2. **Check Root Scoping Attributes**:
   Run in the host console:
   `document.documentElement.getAttribute('data-w95-theme')` and host flags like `document.documentElement.getAttribute('data-w95-chatgpt')`.
   If null, a framework has wiped the root attributes after initial execution. Verify the root `MutationObserver` covers that host flag.

3. **Check for Recursion / Startup Exceptions**:
   Verify console errors for `Maximum call stack size exceeded`. Ensure no callback closure shadows outer functions of the same name.
