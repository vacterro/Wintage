# ADR-007 — BetterDiscord plugins are maintained outside this repository

Date: 2026-10-05. Ticket T-413 (SRC-064).

## Context

Wintage shipped two copies of the same standalone BetterDiscord plugins: a
payload tree under `desktop/targets/betterdiscord/plugins/` and a second
distribution folder `updated_discord_plugins/` at the repository root, with the
WinForms installer (`desktop/WintageInstaller.ps1`) discovering, copying,
enabling and state-recording them through `bdPlugins*` variables and
`Get-BdPlugin*`/`Load-BdPlugins` helpers. Both copies drifted from the upstream
plugin sources, and the installer carried a full plugin manager UI (checklist,
Select All/None, Apply/Uninstall, plugin folder, refresh, `BetterDiscord\plugins`
writes and `BetterDiscord\data\stable\plugins.json` state).

## Decision

Wintage distributes the BetterDiscord **theme** target only. Standalone
BetterDiscord plugins are maintained in one canonical repository:

```
https://github.com/vacterro/BetterDiscord_vac34_plugins
```

The installer's BetterDiscord tab is a navigation page: a title, the sentence
"Standalone BetterDiscord plugins are maintained in a separate repository."
and one button that opens the canonical URL. Wintage contains no `*.plugin.js`
payload, no plugin manager code, no plugin state file, and no `updated_discord_plugins`
directory.

## Consequences

- The BetterDiscord theme target (`desktop/targets/betterdiscord/template.css`)
  is unaffected and still installs.
- `tools/test-bd-architecture.ps1` fails the suite if a plugin payload, the
  duplicate distribution directory, a removed manager symbol, or an installer
  write into the BetterDiscord plugins paths returns, and if the canonical URL
  disappears from the installer page or the READMEs.
- Locale keys that existed only for the deleted manager UI are gone from all 33
  locale files; only `BdPlugins`, `BdRepoDesc` and `BdRepoOpen` remain for the
  link page.
- Plugin feature work, versions and release notes live in the canonical
  repository, never here.
