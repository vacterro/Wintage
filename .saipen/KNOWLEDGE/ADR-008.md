# ADR-008 — A ticket commit carries only that ticket's scope

Date: 2026-10-05. Ticket T-418 (improve cycle imp-vacterro-wintage-20261005-4, RUN-1/IMP-005).

## Context

The T-413 commit `c528ef3` was made with an explicit pathspec, never `git add -A`,
and still carried 372 paths: 102 were the ticket's own delta and 256 were
per-event journals under `.saipen/recovery/log-detail/` for events E-2335..E-3237
that earlier waves had left uncommitted. A directory-scoped add takes a backlog
as a unit, and `.saipen/recovery/log-detail/` is a tracked directory, so nothing
in the worktree showed the sweep before the commit. The SHIP phase already
forbids widening adds (`phases/ship.md` 6b.4) and asks the shipper to "re-read the
index and prove it equals the intended scope" (6b.5), but that proof had no
mechanical form, so a green `git diff --cached` could still hide 250 unattributed
paths.

## Decision

A commit belongs to exactly one ticket, and every path in it must be one of:

- a product path (outside `.saipen/`), or a path passed to the gate with `-Path`;
- a standard per-operation memory surface: `.saipen/BOARD.md`, `STATE.md`,
  `LOG.md`, `MANIFEST.json`, `IDENTITY.md`;
- a per-event journal whose event this commit's **own added `LOG.md` lines**
  carry under this ticket's own `[T-###]` owner tag.

`tools/test-commit-scope.ps1` enforces this against the staged index (before
commit, the moment 6b.5 asks for) or against a named commit (after the fact).
It also refuses an added `LOG.md` line that carries another ticket's owner tag:
that is the uncommitted backlog itself, not a shadow of it. One case is legal
when it is declared: `-AlsoOwns T-###,…` names the sibling tickets a single
operation created — closing one improve cycle files a follow-up ticket per
finding, and those ticket-add lines (with their journals) land in the same
`LOG.md` the closing ticket commits. Declaring them makes the extra scope
explicit and counted rather than accidental; declaring ninety-two tickets is not
a plausible accident, and the paths clause still applies to their journals.
Memory surfaces under
`.saipen/` that are not on the list above — knowledge cards, archive moves,
improve cycles — must be named with `-Path`, so a sweep of them cannot be
accidental.

## Consequences

- A scope violation is named, not inferred: the gate prints the offending path
  count and the first ten paths, so the commit can be corrected before it exists.
- The gate is non-vacuous by construction. Its `-RedControl` builds a scratch
  repository and requires PASS on an own-scope commit, FAIL naming a foreign
  event journal, FAIL naming another ticket's `LOG.md` line, and PASS again when
  the foreign journal is declared with `-Path`.
- The regression clause in `tests/Run-Tests.ps1` runs the gate against the real
  violator `c528ef3` with `-ExpectReject`, so the gate cannot be weakened into
  passing the commit that motivated it without the suite going red.
- Committing a ticket now costs one extra command before the commit, and a
  legitimate multi-ticket release commit must name its extra memory paths with
  `-Path` rather than relying on a subject-line ticket.
- Both this ADR and `CHANGELOG.md` are outside the standard memory surfaces, so
  this ticket's own commit must name them explicitly. That is intended: the rule
  is only credible if it binds its own author.
