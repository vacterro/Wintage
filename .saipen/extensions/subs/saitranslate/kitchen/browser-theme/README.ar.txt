Vintage Win 95 Dark Golden — سمة المتصفح (Cent Browser / Chrome / Edge)
==========================================================================

سمة مرافقة لسكربت مستخدم Wintage (https://github.com/vacterro/Wintage).
هذه السمة لوحة Dark Golden ثابتة قديمة، مرفقة يدوياً ومستقلة عن لوحات السكربت القابلة
للتبديل: canvas #1A0F05، toolbar #2A1C0A، نص ذهبي #D4B87A، ذهبي الحواف #C0A060،
حقل العنوان الغائر #0F0A04، تمييز الروابط #9DD9F9. لا تتبع اللوحة الافتراضية للسكربت
(Golden Default) ولا حزم themes/*.json — تبقى على المظهر الذهبي الداكن الكلاسيكي
الذي بُنيت عليه سمة المتصفح هذه.

INSTALL:
  1. افتح chrome://extensions
  2. فعّل "Developer mode" (أعلى اليمين)
  3. اضغط "Load unpacked" واختر هذا المجلد (vintage_theme)
  4. تُطبَّق السمة فوراً. أعد تحميلها بالطريقة نفسها بعد التعديلات.

REVERT:
  Settings -> Appearance -> "Reset to default"، أو أزل السمة
  من chrome://extensions.

تخطيط الرموز:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
