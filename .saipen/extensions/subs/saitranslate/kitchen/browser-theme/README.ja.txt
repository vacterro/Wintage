Vintage Win 95 ダークゴールデン — ブラウザテーマ (Cent Browser / Chrome / Edge)
==========================================================================

Wintageユーザースクリプト (https://github.com/vacterro/Wintage) のコンパニオンテーマ。
このテーマは固定のレガシーなダークゴールデンパレットであり、手でバンドルされ、
ユーザースクリプトの切替可能なパレットから独立している: キャンバス #1A0F05、ツールバー #2A1C0A、金色テキスト
#D4B87A、ベベルゴールド #C0A060、沈み込みオムニボックス #0F0A04、リンクアクセント #9DD9F9。
スクリプトのデフォルト (Golden Default) や themes/*.json パックには追従しない —
このブラウザテーマが作られたときのクラシックなダークゴールデンの見た目のままである。

インストール:
  1. chrome://extensions を開く
  2. "Developer mode" を有効にする (右上)
  3. "Load unpacked" をクリックし、このフォルダ (vintage_theme) を選択する
  4. テーマはすぐに適用される。編集後も同じ方法で再読み込みする。

元に戻す:
  Settings -> Appearance -> "Reset to default"、または chrome://extensions から
  テーマを削除する。

トークンのマッピング:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
