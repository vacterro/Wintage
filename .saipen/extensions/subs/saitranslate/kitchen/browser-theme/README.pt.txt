Vintage Win 95 Dark Golden — tema para navegador (Cent Browser / Chrome / Edge)
==========================================================================

Tema complementar para o userscript Wintage (https://github.com/vacterro/Wintage).
Este tema é uma paleta Dark Golden legada fixa, empacotada manualmente e independente
das paletas alternáveis do userscript: canvas #1A0F05, toolbar #2A1C0A, golden text
#D4B87A, bevel gold #C0A060, sunken omnibox #0F0A04, link accent #9DD9F9. Ele não
acompanha o padrão do script (Golden Default) nem os pacotes themes/*.json — ele
permanece no visual Dark Golden clássico com o qual este tema de navegador foi criado.

INSTALAÇÃO:
  1. Abra chrome://extensions
  2. Ative o «Developer mode» (canto superior direito)
  3. Clique em «Load unpacked» e selecione esta pasta (vintage_theme)
  4. O tema é aplicado imediatamente. Recarregue-o do mesmo modo após edições.

REVERTER:
  Configurações -> Aparência -> «Reset to default», ou remova o tema
  de chrome://extensions.

Token mapping:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
