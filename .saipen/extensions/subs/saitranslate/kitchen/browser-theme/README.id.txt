Vintage Win 95 Dark Golden — tema peramban (Cent Browser / Chrome / Edge)
==========================================================================

Tema pendamping untuk skrip pengguna Wintage (https://github.com/vacterro/Wintage).
Tema ini adalah palet Dark Golden warisan yang tetap, dibundel manual dan independen
dari palet yang dapat dialihkan skrip pengguna: canvas #1A0F05, toolbar #2A1C0A,
teks emas #D4B87A, bevel gold #C0A060, omnibox cekung #0F0A04, link accent #9DD9F9.
Ia tidak mengikuti default skrip (Golden Default) maupun paket themes/*.json — ia
tetap pada tampilan Dark Golden klasik tempat tema peramban ini dibangun.

INSTALL:
  1. Buka chrome://extensions
  2. Aktifkan "Developer mode" (kanan atas)
  3. Klik "Load unpacked" dan pilih folder ini (vintage_theme)
  4. Tema langsung berlaku. Muat ulang dengan cara yang sama setelah edit.

REVERT:
  Settings -> Appearance -> "Reset to default", atau hapus tema
  dari chrome://extensions.

Token mapping:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
