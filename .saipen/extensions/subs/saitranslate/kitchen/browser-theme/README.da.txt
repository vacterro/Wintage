Vintage Win 95 Dark Golden — browsertema (Cent Browser / Chrome / Edge)
==========================================================================

Ledsagertema til Wintage-userscriptet (https://github.com/vacterro/Wintage).
Dette tema er en fast, ældre Dark Golden-palette, håndpakket og uafhængig af
userscriptets skiftbare paletter: canvas #1A0F05, værktøjslinje #2A1C0A, gylden tekst
#D4B87A, bevel-guld #C0A060, sænket omnibox #0F0A04, linkaccent #9DD9F9. Det
følger ikke scriptets standard (Golden Default) eller themes/*.json-pakkerne — det
bliver ved det klassiske Dark Golden-look, som dette browsertema blev bygget med.

INSTALLÉR:
  1. Åbn chrome://extensions
  2. Aktivér "Udviklertilstand" (øverst til højre)
  3. Klik på "Indlæs upakket" og vælg denne mappe (vintage_theme)
  4. Temat anvendes med det samme. Genindlæs det på samme måde efter ændringer.

FORTYD:
  Indstillinger -> Udseende -> "Nulstil til standard", eller fjern temaet
  fra chrome://extensions.

Token mapping:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
