Vintage Win 95 Dark Golden — browserthema (Cent Browser / Chrome / Edge)
==========================================================================

Begeleidend thema voor de Wintage userscript (https://github.com/vacterro/Wintage).
Dit thema is een vast legacy Dark Golden-palet, handmatig gebundeld en onafhankelijk
van de wisselbare paletten van de userscript: canvas #1A0F05, toolbar #2A1C0A,
golden text #D4B87A, bevel gold #C0A060, sunken omnibox #0F0A04, link accent
#9DD9F9. Het volgt niet de standaard van het script (Golden Default) noch de
themes/*.json-pakketten — het blijft bij de klassieke Dark Golden-look waarmee dit
browserthema is gebouwd.

INSTALLEREN:
  1. Open chrome://extensions
  2. Schakel «Developer mode» in (rechtsboven)
  3. Klik op «Load unpacked» en selecteer deze map (vintage_theme)
  4. Het thema wordt direct toegepast. Laad het na bewerkingen op dezelfde manier opnieuw.

TERUGDRAAIEN:
  Instellingen -> Uiterlijk -> «Reset to default», of verwijder het thema
  uit chrome://extensions.

Token mapping:
  frame / ntp_background   #1A0F05  (canvas)
  frame_inactive / toolbar #2A1C0A  (surface)
  frame_incognito          #0F0A04  (compare-back)
  omnibox_background       #0F0A04  (sunken field)
  tab_text / ntp_text      #D4B87A  (golden primary)
  tab_background_text      #B09558  (golden secondary)
  ntp_header               #C0A060  (bevel highlight)
  button_background        #362812  (raised)
  ntp_link                 #9DD9F9  (accent)
