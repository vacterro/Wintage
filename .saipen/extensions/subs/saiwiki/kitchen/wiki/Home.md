# Wintage

**Win95 Dark Golden Vintage theme for the whole web.** A Tampermonkey userscript
that restyles every site into a dark golden-brown Windows 95 application:
pixel-sharp 3D bevels, zero rounded corners, zero animations, no hover flashbangs,
Verdana everywhere.

The modern web optimizes for aesthetics at the expense of usability. Wintage brings
back explicit visual language: raised buttons, sunken inputs, sharp boundaries,
consistent typography, zero distractions, and immediate state changes. Every
element communicates its purpose at a glance.

## Quick facts

- **Current version:** 1.26.3 (2026-08-10)
- **Palettes:** sixteen, switchable per user from the Tampermonkey menu
- **Scope:** every site, plus desktop applications (see [Desktop](Desktop))
- **License:** MIT

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Opera, Safari).
2. Click **[Install Wintage](https://raw.githubusercontent.com/vacterro/Wintage/main/wintage.user.js)**.
3. Done.

Full instructions: [Installation](Installation)
